# UI Audit: OSAS Monitoring Table

Scope: OSAS Monitoring proposal and post-event tables, their filters, and table badges.

## Findings

1. **[LOW] Separate event and organization fields in the tables and filters** — `next-app/src/components/staff/OsasMonitoringTab.js`: proposal and post-event rows combine the event title and organization in one column, while the organization filter is separate and there is no structured event-title filter. Split the table fields and size them to their content so people can scan, sort, and filter each value independently. *(R-20, C-3)*

2. **[LOW] Align compact badge corner radii** — `next-app/src/components/staff/OsasMonitoringTab.js`: acronym, CBL, officer-position, and post-event labels use `rounded`, unlike the shared radius hierarchy for compact badges; use the standard `rounded-lg` treatment while retaining full-pill status badges. *(R-11)*
